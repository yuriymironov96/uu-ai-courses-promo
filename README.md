# Курси ШІ — Університет «Україна» та Фаховий коледж «Освіта»

Статичний сайт для дня відкритих дверей. Два курси для школярів та абітурієнтів, кожен — **4 заняття по 1 годині**:

- **Вступ до розробки ШІ-застосунків** — основи ШІ, автоматизація в n8n, власний помічник та робота з документами.
- **Штучний інтелект на повну** — огляд технології та щоденне використання ШІ з основним фокусом на промптингу.

Звичайні HTML, CSS і JavaScript. Без збірки, зовнішніх бібліотек, аналітики та запитів до моделей. Реєстрація на курси відбувається поза сайтом.

Оформлення адаптовано до [iict.uu.ua](https://iict.uu.ua): темно-синій `#1a2a3a`, синьо-бірюзовий `#1a5f7a`, біле тло, заокруглені картки та курсивні акценти. Шрифти системні, без зовнішнього завантаження. На слайдах наведені короткі тези; повні біографії доступні в блоках «Про викладача».

## Локальний перегляд

Відкрий `index.html` у браузері або запусти з кореня репозиторію:

```sh
python3 -m http.server 8000
```

Відкрий <http://localhost:8000>.

## GitHub Pages

Після додавання файлів у `main` відкрий **Settings → Pages**:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

Очікувана адреса після увімкнення Pages: <https://yuriymironov96.github.io/uu-ai-courses-promo/>. Файл `.nojekyll` вимикає обробку Jekyll. Відносні шляхи працюють із префіксом репозиторію. Якщо змінюєш адресу сайту, онови `canonical` та `og:url` у `index.html`.

## Режим презентації

Натисни **«Презентація»** у верхній панелі. Кожна секція стане окремим екраном. Високі секції можна прокручувати.

- **← / →**, **Page Up / Page Down** — попередня / наступна секція.
- **Home / End** — перша / остання секція.
- **Esc** — повернутися до звичайного перегляду.
- Кнопки внизу працюють також із телефона.

Для повноекранного показу скористайся повноекранним режимом браузера.

## Редагування

- `index.html` — описи, програми, викладачі та посилання.
- `styles.css` — оформлення, адаптивність, презентація та друк.
- `script.js` — приклади промптів і керування презентацією.
- `assets/` — локальні фотографії та піктограма сайту. Піктограма — графічний елемент сайту, а не офіційний логотип закладів.

### Реєстрація

Кнопки на першому та завершальному екранах відкривають [Google Форму](https://forms.gle/TKTWT9XYddsvK9cC8). Власної форми на сайті немає.

`assets/registration-qr.png` кодує те саме посилання та доступний на завершальному слайді. Якщо змінюється адреса реєстрації, потрібно оновити посилання в HTML і QR-код.
